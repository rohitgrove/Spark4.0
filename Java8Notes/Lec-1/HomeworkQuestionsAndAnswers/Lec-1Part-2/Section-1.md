# Question 1

## Question

**Programming Paradigm kya hota hai?**

---

# Answer

Programming Paradigm ka matlab hota hai

> **Programming karne ka ek style, methodology ya approach jiske through hum software develop karte hain.**

Simple language me samjho.

Ek hi problem ko solve karne ke kai tareeke ho sakte hain.

Programming me bhi ek hi problem ko solve karne ke multiple styles hote hain.

Inhi styles ko

> **Programming Paradigm**

kehte hain.

Paradigm ye decide karta hai ki

* Program ka structure kaisa hoga.
* Code kis tarah organize hoga.
* Logic kaise likha jayega.
* Data aur behavior ka relation kya hoga.

Ye sirf syntax ka difference nahi hota.

Ye programming sochne ka tareeka hota hai.

# Interview Tip

Interviewer

> Why is Java called a Multi-Paradigm Language?

Best Answer

Java is primarily an Object-Oriented Programming language, but from Java 8 onward it also supports Functional Programming features such as Lambda Expressions, Functional Interfaces and Stream API. Therefore, Java can be considered a Multi-Paradigm language.
